# Voice Mode
- Push-to-talk is the default mode.
- Voice capture is user-initiated only.
- No background always-listening or wake-word behavior is implemented.
- Mic + speech permissions are requested only after user initiation.

- VoiceModeView now uses VoiceSessionController as primary runtime; VoiceService retained as compatibility backend for speech engine bridging only.
- Voice permission prompts are user-initiated from push-to-talk action; no startup prompt and no background always-listening.

## Build integration notes

Voice usage depends on microphone and speech-recognition Info.plist strings generated by the Xcode project. VoiceMode remains foreground and user-initiated only.

## Scene transition resource policy

- Voice generation is allowed to request model work only from an explicit user voice turn.
- When the scene becomes inactive or backgrounded, VoiceMode performs nonblocking cancellation: active generation is cancelled, speech recognition is interrupted, and TTS is stopped.
- VoiceMode scene handlers must not await model loading, memory extraction, RAG work, or diagnostics refresh; foreground re-entry requires a fresh user action.
